## Read this first: Suno is a music tool

Suno writes *songs*. It is the right tool for the ten music tracks and the
four ambience beds below, and the wrong tool for a 200 ms sword impact -
ask it for one and you get a two-minute track that happens to open with a
clang.

For the one-shots, use a sound-effect generator instead. **ElevenLabs Sound
Effects** (elevenlabs.io/sound-effects) is free-tier friendly and takes the
same plain-English prompts. **Freesound.org** is the other good option if you
would rather use recorded audio - check each licence.

You can absolutely try these in Suno. Just trim hard afterwards, and expect
to throw most of them away.

---

## Where the files go

```
game/audio/music/      music_*.ogg      long, looping
game/audio/ambience/   ambience_*.ogg   long, looping, quiet
game/audio/sfx/        sfx_*.ogg        short one-shots
```

**Drop whatever you generate into `audio_inbox/` and I will convert,
normalise, trim and file it.** Name it after the `id` column - extension does
not matter, mp3/wav/ogg/flac all fine. The conversion is not optional busywork:
Godot cannot loop an MP3 seamlessly (the format pads the start and end of every
file), so anything that loops has to become OGG.
